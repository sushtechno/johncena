Voicing notes baked into the engine

  • AudioWorklet processing keeps the synth off the UI thread for low-latency note response.
  • 7-string presets are tuned around low B and drop A; baritone presets sit lower with longer virtual scale tension.
  • Pre-emphasis, asymmetric clipping, power-amp sag, and post-cab filtering are stacked for saturated but percussive distortion.
  • The noise gate uses fast attack/release with hysteresis so palm mutes clamp down between chugs.
  • MIDI learn maps hardware CCs to every amp, stomp, cabinet, gate, and performance parameter.
