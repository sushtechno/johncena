# SkyFetch - API Weather Dashboard (Part 2)

Interactive weather dashboard with:

- city search input + button
- async/await weather fetching with Axios
- loading spinner
- error handling for invalid input/city
- Enter key support

## Setup

1. Open `app.js` and set your OpenWeatherMap API key:

```js
const API_KEY = "YOUR_OPENWEATHERMAP_API_KEY";
```

2. Open `index.html` in your browser.
